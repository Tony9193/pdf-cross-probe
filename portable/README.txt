PDF 联动查看器 v1.1.1 - Windows 便携版

运行环境：Windows 10/11，64 位。
将整个文件夹解压到本机目录，双击 PDF Cross Probe.exe 或 Start.cmd。
不要只拷贝 EXE；resources、DLL、pak 等文件必须一起保留。
无需安装 Python、Node.js、WebView2，也无需启动本地服务器或联网。
未使用代码签名，Windows 或公司终端安全策略可能要求确认或管理员放行；不要关闭安全软件。

打开图纸：在 A、B 面板打开 PDF，或将 PDF 拖到对应面板。加密 PDF 会在对应面板提示输入密码，支持密码错误重试与取消。
每个面板的连续阅读按钮独立控制；设置内可选“不翻页”“多页滚动”“单页”。不翻页仅按钮翻页；多页滚动上下连排；单页模式滚到边界继续滚动可翻页，带惯性防误翻。
面板标题栏的关闭按钮会释放图纸并回到空白。再次启动 EXE 或点击“新建窗口”可打开独立空白工作区，关键词不会与其他工作区混在一起。
外部右键/双击打开：在右上角「设置」中可一键注册 Windows 右键菜单（用 PDF 联动查看器打开 / 作为 A 图打开 / 作为 B 图打开）与系统「打开方式」候选（无需管理员权限，亦可随时一键取消）。从资源管理器打开 PDF 时，每次都可选择「新建独立工作区」或放入「已有工作区的 A / B」（例如同时打开两组共 4 份不相关图纸，每组内部联动、组间互不干扰）；若目标位置已有图纸，会先显示原文件名并确认后才替换。
关闭抓手后可用鼠标拖选 PDF 文字，选区显示蓝色；Ctrl+C 或右键菜单可复制，Ctrl+V 或右键可粘贴到输入框或其他程序。无可提取文字的图纸不能这样选字。
拖动两份图纸之间的分隔条可调整面板大小，拖到底可平滑收起该侧面板并在边缘留下三角形展开按钮（点击或向内拖动即可恢复），双击分隔条恢复居中；支持一键互换 A/B 位置、收起左侧搜索栏、90° 旋转图纸（快捷键 R）以及浅色/暗黑 CAD/跟随系统主题切换。
已验证标准 RC4、AES-128、AES-256 密码 PDF，可用已知打开密码或所有者密码解锁；不提供密码破解。
PDF 密码只在当前会话内存中使用，双窗口仅在本机同步，不写入应用配置、URL 或日志，退出后需重新输入。
搜索：每行一个位号或网络名，点击追加高亮。点击图纸文字也能触发联动。
图纸点击会保留源面板位置，并让另一份 PDF 定位到首个命中。
侧边箭头遍历每一处命中；连续点击当前页按钮在该页内轮询。
抓手按钮开启左键拖动；中键可直接拖动。Ctrl + 滚轮在鼠标位置缩放。
缩放范围 10% 至 3200%；精绘使用方向预绘和有界并发，持续滚动不会无限推迟补绘，小幅拖动直接复用。
单页缓存最近 3 页，连续阅读优先保留可见页和正在选择的文字，离屏页按预算释放。复杂图纸首次绘制仍可能需要等待。
已看页面的最近高清视野也可复用；首次翻页先显示预览再完成文字层和高清。
缓存有像素/页数上限，切换文件后会清空；特别复杂图纸首次绘制仍可能需要等待。
两种高亮模式可切换；各面板独立翻页和缩放。
双屏窗口把 B 面板放到独立桌面窗口，可拖到第二台显示器。
点击恢复双栏或关闭 B 窗口可返回双栏，并保留页码、缩放、旋转与观察位置；关闭主窗口只关闭它自己的 B 窗口，所有窗口关闭后才退出。

在线更新：设置内可自动检查固定 GitHub 仓库的稳定版本，下载可取消，安装需单独确认关闭所有窗口。仅更新主进程联网，不发送图纸和路径。
更新包必须通过内置公钥、签名清单、SHA-256 和逐文件校验；这不等于 Windows 代码签名。会暂存新版、保留旧版备份，新版无法启动时回滚。
更新中断时保留本机配置目录 updates 下的事务日志、助手和旧版备份，可用该事务的助手恢复。无写权限、网络或组织策略限制时使用 GitHub 手动下载，不自动提权。
GitHub v1.0.0 没有更新器，首次升级需要手动下载本版。重启后图纸需重新打开，加密 PDF 需重新输入密码。

文件只在本机读取，原 PDF 不会被修改，也不会上传图纸。
精确匹配为零时，按“关键词 × 完整文档”降级包含匹配；成功命中标为容错。
对于符合识别条件的 PDF 不可见 PAU 位号标记，可直接按位号点击和精确查找，原始标记仍可搜索；其他标记格式不作推断。
可对单面板开启强制容错。无文字层文件仅查看，不做 OCR 或区域标注。
文字高亮不代表已验证电气连接；只有 PDF 时不能自动推断实际铜箔网络。
扫描图片放大清晰度受原始分辨率限制。

本版不恢复退出前打开的图纸；再次启动需重新选文件。
