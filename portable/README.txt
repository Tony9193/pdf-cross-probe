PDF 联动查看器 v0.1.1 - Windows 便携版

运行环境：Windows 10/11，64 位。
将整个文件夹解压到本机目录，双击 PDF Cross Probe.exe 或 Start.cmd。
不要只拷贝 EXE；resources、DLL、pak 等文件必须一起保留。
无需安装 Python、Node.js、WebView2，也无需启动本地服务器或联网。
未使用代码签名，Windows 或公司终端安全策略可能要求确认或管理员放行；不要关闭安全软件。

打开图纸：在 A、B 面板打开 PDF，或将 PDF 拖到对应面板。
搜索：每行一个位号或网络名，点击追加高亮。点击图纸文字也能触发联动。
图纸点击会保留源面板位置，并让另一份 PDF 定位到首个命中。
侧边箭头遍历每一处命中；连续点击当前页按钮在该页内轮询。
抓手按钮开启左键拖动；中键可直接拖动。Ctrl + 滚轮在鼠标位置缩放。
缩放范围 10% 至 3200%；高精度图层向窗口每边预绘约 15%，小幅拖动直接复用。
翻页缓存最近 3 页的预览和文字层，当前页完成后闲时预加载前后页。
已看页面的最近高清视野也可复用；首次翻页先显示预览再完成文字层和高清。
缓存有像素/页数上限，切换文件后会清空；特别复杂图纸首次绘制仍可能需要等待。
两种高亮模式可切换；各面板独立翻页和缩放。
双屏窗口把 B 面板放到独立桌面窗口，可拖到第二台显示器。
点击恢复双栏或关闭 B 窗口可返回单窗口；关闭主窗口会退出整个应用。

文件只在本机读取，原 PDF 不会被修改，也不会上传图纸。
精确匹配为零时，按“关键词 × 完整文档”降级包含匹配；成功命中标为容错。
可对单面板开启强制容错。无文字层文件仅查看，不做 OCR 或区域标注。
文字高亮不代表已验证电气连接；只有 PDF 时不能自动推断实际铜箔网络。
扫描图片放大清晰度受原始分辨率限制。

本版不恢复退出前打开的图纸；再次启动需重新选文件。
